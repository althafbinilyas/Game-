## 🎮 How to Play

### Controls
- **Desktop**:
  - <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> or <kbd>Arrow Keys</kbd> to move Pip the character.
  - <kbd>P</kbd> or <kbd>Esc</kbd> to Pause / Resume.
- **Mobile / Tablet**:
  - Use the on-screen responsive **Arcade D-Pad** (▲ ◀ ▼ ▶) designed for comfortable thumb touch controls.
- **HUD Buttons**:
  - ⏸️ Pause, 🔄 Restart, 🔊 SFX toggle, 🎵 Music toggle.

### Objective
1. Collect all gold coins before the **60-second countdown timer** runs out!
2. Snag rare **Star Gems** for +50 bonus points.
3. Dodge grumpy patrolling **Slimes**, bouncing **Bats**, and the stalking **Magma Hound**.
4. Beat all **3 challenging levels** to win the game and set the highest score!

## 🌟 Features

- **Cute Character**: Features squash-and-stretch movement, bobbing ears, directional eyes, dust trails, and invulnerability damage frames.
- **3 Progressive Levels**:
  - **Level 1 (Sunny Meadow)**: Gentle green meadows, slow slimes, and hedges.
  - **Level 2 (Twilight Grove)**: Sunset atmosphere, bouncing bats, spikes, and moving laser barrier.
  - **Level 3 (Magma Vault)**: Fiery labyrinth, magma bouncing hazards, and a tracking hound enemy.
- **Procedural Web Audio API Sound Effects**: Zero external mp3/wav files required! 100% self-contained chimes, fanfares, bounces, hits, and cheerful background synthesizer tunes.
- **Vibrant Cartoon Aesthetic**: Parallax cloud animation, rolling hills, modern Google Font ('Fredoka'), and glassmorphism HUD.
- **Persistence**: High score automatically saved to `localStorage`.
- **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript.

## 🚀 Running Locally

No installation or build step needed!

1. Clone the repository:
   ```bash
   git clone https://github.com/althafbinilyas/Game-.git
   cd Game-
   ```
2. Open `index.html` directly in your browser, or start a lightweight server:
   ```bash
   python -m http.server 8000
   ```
3. Visit [http://localhost:8000/](http://localhost:8000/) in any web browser.
